## Iterating on the script

```bash
# After every edit to main.ts:
SwitchScriptTool --transpile <this-folder>
```

- Code-only changes are picked up automatically — no need to deactivate the flow.
- If you change the **declaration** (added/renamed property, changed connection rules) in SwitchScripter, deactivate the flow first, then right-click the Script element → **Reload script package**.

## Debugging

1. In Switch Designer: Script element → **Enable debug mode** = Yes, Port 9229, select entry points to debug.
2. Activate the flow → drop a job. Switch pauses waiting for the debugger.
3. In VS Code: open this folder → press F5 (uses `.vscode/launch.json`).
4. **Set Enable debug mode back to No when finished**, or the flow will hang waiting for a debugger next time.

## Packing for production

```bash
# Slim node_modules (removes devDependencies):
npm prune --production

# Pack — produces <ScriptID>.sscript next to <DestinationFolder>:
SwitchScriptTool --pack <this-folder> <DestinationFolder>

# Optional password protection (Enfocus cannot recover a lost password):
SwitchScriptTool --pack <this-folder> <DestinationFolder> --password <Password>

# Verify contents:
SwitchScriptTool --list <DestinationFolder>/<ScriptID>.sscript
```

In Switch Designer, swap the Script element's `Script package` from this dev folder's placeholder to the produced `.sscript` (copy property values via context menu, paste back after swapping).
